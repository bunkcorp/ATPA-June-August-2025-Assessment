### 1.1.3 Software for Module 3

Python currently has great functionality for processing data and implementing many predictive models. Unfortunately, the current Python implementation (as of March 2022) of many of the models to be covered in Module 3 have significantly less functionality than their R counterparts. For example, additive models can be fit in Python using statsmodels, but it requires a lot of specification that the R package mgcv does automatically.
